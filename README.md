# -
flexcard - это сервис виртуальных карт для рекламы (Facebook, Google, TikTok и др. международных рекламных кабинетов).
Если коротко, то у нас более 60 000 активных пользователей по всему миру, за последний год мы выпустили свыше 5 000 виртуальных карт, 35 транзакций в минуту. 

Наша аудитория - вебмастера и арбитражные команды. На сегодняшний день нашими партнерами являются: Dolphin Anty, MoreLogin, Vision, Fb Killa, Partnerkin и другие крупные сервисы, партнерки и арбитражные медиа.

Будем рады с вами посотрудничать. Если вам интересно, свяжитесь пожалуйста со мной, чтобы обсудить детали: @Mari_flexcard
